# Security Policy

The Tadah! security reporting policy is documented in the umbrella
project:

<https://git.ecdf.ed.ac.uk/tadah/tadah.mlip/-/blob/develop/SECURITY.md>

In short: report security issues as a **confidential issue** on the
affected module's GitLab project (tick the *Confidential* checkbox).
Do not open a public issue or merge request for a security report.
