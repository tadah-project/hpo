# Security Policy

The Tadah! security reporting policy is documented in the umbrella
project:

<https://github.com/tadah-project/tadah.mlip/blob/v1-dev/SECURITY.md>

In short: report a security issue privately, with *Report a
vulnerability* on the Security tab of the umbrella project
(<https://github.com/tadah-project/tadah.mlip/security/advisories/new>),
or of Tadah!LAMMPS for the LAMMPS plugin
(<https://github.com/tadah-project/tadah.lammps/security/advisories/new>).
Do not open a public issue or pull request for a security report.
