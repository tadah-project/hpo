# The runs of the Nested Fitting pages: one line per run of the commands of
# a page under CTest (tadah_nfp_<id>, label examples;
# tests/nfp_docs/check_nfp_run.py runs them and describes each field).
# Every page under docs/source/nfp that runs tadah in a bash code block,
# and every directory here that holds a target file (*.hpo) or a training
# configuration (*.train), needs a line: tadah_docs_tools fails otherwise.
#
#   <id> | <page.rst> | <dir> | <labels> | <timeout> | <tolerances>
#        [| <searches>]
#
# id          the CTest entry is tadah_nfp_<id> (letters, digits, '_')
# page.rst    the page whose bash code blocks run, relative to docs/source
# dir         the directory they run in, relative to this directory; it
#             holds expected.csv (Quantity,Value), the results the page
#             quotes
# labels      CTest labels besides examples, separated by ',', or '-';
#             slow: a run longer than about two minutes, whose page needs
#             a second line without slow, a short variant
# timeout     seconds the commands may take together: a limit that stops
#             a run that hangs, about 30 times the time of the run on a
#             quiet machine and at least 900
# tolerances  <name>=<relative tolerance> or <name>=abs:<tolerance>,
#             separated by ',', or '-'; one per kind of row of
#             expected.csv, named as check_nfp_run.py lists them
#             (best_loss=1e-3, best_rcut2b=abs:0.01, energy_rmse=0.01);
#             each at least the class of its rows (check_nfp_run.py,
#             "Tolerance classes"): a loss 1e-3, a length abs:0.01 (Å), a
#             count abs:0, every other quantity 1e-2, and a "- DFT" row
#             1e-2 of its property, rounded up to one significant digit
# searches    optional: the searches of the page the line runs, separated
#             by ',', each the --hpotarget argument as the page writes it
#             or run <n>; each runs with the commands after it up to the
#             next search, and only their rows of expected.csv are
#             measured. Without it the line runs every command.
#
# A tolerance looser than its class is named in the comment above its
# line. It covers the results of the line on five BLAS code paths (MKL on
# its default and its compatible path, OpenBLAS loaded in its place on
# its SkylakeX, Haswell and Nehalem kernels): twice the largest difference from the value of
# expected.csv, rounded up to one significant digit. A search that compares
# two losses otherwise on another path can take another way and end at
# another point, after another number of evaluations when a test on the
# loss stops it. Where the loss is flat near the best, the tolerance also
# covers the spread of the quantity (for an error, of the validation error
# of its kind) over the evaluations whose loss lies within 1e-3 of the best
# loss.
