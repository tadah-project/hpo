# Code of Conduct

This project follows the Tadah! project Code of Conduct, hosted in
the umbrella repository:

<https://git.ecdf.ed.ac.uk/tadah/tadah.mlip/-/blob/v1-dev/CODE_OF_CONDUCT.md>

To report unacceptable behaviour, file a **confidential issue** on
the relevant module's GitLab project (tick the *Confidential*
checkbox before submitting).
